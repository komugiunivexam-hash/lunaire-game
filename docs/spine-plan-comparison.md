## 結論

- **Essential（$69・買い切り）**: ボーンで画像パーツを動かすアニメは全部作れる

- **Enterprise（$2,499〜/年）**: 機能は Pro と同じ。年商 50 万ドル以上の企業向け

価格は調査時点の値。購入前に https://esotericsoftware.com/spine-purchase で確認すること。

## LUNAIRE での推奨: Professional

### 今の「人形感」の原因（src/main.js `drawPlayer`）

- 状態ごとに 1 枚絵（idle / run / slash / parry / hit）を切り替えているだけ
- 動きは画像全体の拡大縮小・上下の揺れ・傾きのみ。体の部位が個別に動かない
- 状態の切り替えが瞬間的で、ポーズ間のつなぎがない

### Professional が必要な理由

| 主人公の特徴 | 自然に見せるのに必要な機能 | プラン |
|---|---|---|
| 長いツインテール・リボン・スカート・鎖 | 物理制約（自動の揺れ） | Pro |
| 塗りの細かいイラスト調 | メッシュ＋ウェイト（関節で絵を曲げる） | Pro |
| 両手で持つ槍、踏み込み | IK（両手を槍に固定、足を接地） | Pro |
| 回避・斬撃の勢い | メッシュ変形（伸び縮み） | Pro |

Essential だと部位ごとの硬い画像を回すだけになり、関節で絵が折れて見えるため、人形感が残る。

### 導入に必要なこと

1. 素材: 1 枚絵のままでは動かせない。基本ポーズ 1 体分を、髪（前・後）・顔・胴・腕・脚・スカート・槍などのレイヤーに分けた PSD を用意し、隠れる部分も描き足す
2. 描画: 現在は Canvas 2D。spine-canvas はメッシュを既定では描画しない（`triangleRendering` が必要で遅い）ため、spine-webgl で別キャンバスに描き、メインの Canvas 2D に `drawImage` で合成する
3. 状態とアニメの対応: idle / walk / dash / slash / parry / hit を Spine のアニメ名に対応させ、切り替えは AnimationState のミックスで補間する
